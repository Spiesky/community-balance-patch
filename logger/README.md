# Battle Logger

The optional Battle Logger add-on is this one script (`script/battle/mod/cbp_battle_logger.lua` in the pack). It is here so anyone can read exactly what it records. At the end of each battle it appends a few lines to `cbp_battle_log.txt` in the game folder; nothing is sent anywhere.

To sum up shared logs: `python3 tools/battle_logs.py log1.txt log2.txt ...`
